# PA4 - User Stories and Project Backlog

PA4 builds on PA3's user accounts, projects, and team memberships. It adds a separate user story backlog for each project.

Users can create, edit, delete, prioritize, and assign stories to project members or leave them unassigned. Each story has a status of To Do, In Progress, or Done. Members cannot be removed while they have assigned stories. Progress summaries, member workload counts, and search filters help organize the backlog. All changes are saved in MongoDB.
