# PA4 - User Stories and Project Backlog

PA4 builds on PA3's accounts, projects, and teams by adding user stories and project backlogs.

You can create and edit stories, choose their priority, and assign them to team members or leave them unassigned. Stories can be marked as To Do, In Progress, or Done. Progress bars, story counts, and filters help you track the work. Before removing a team member, reassign, unassign, or delete their assigned stories, including those marked Done. All changes are saved in MongoDB.
